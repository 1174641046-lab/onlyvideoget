使用帮助

只用批量解析（无需服务器）

  • 双击打开本页面，粘贴视频链接（每行一个，最多 20 个）
  • 点击绿色「批量解析」，自动提取视频、封面、文案、标签

要用逐字稿（需要本地服务器）

  • 双击 start-videoparser.bat → 模型加载后浏览器自动打开页面
  • 粘贴链接，点蓝色「逐字稿解析」→ 解析完成后点「提取并转写」
  • 转写结果自动填入文本框，可编辑后下载 TXT
服务器已在运行时再次双击 bat 不会重复启动，只打开页面；黑色窗口保持打开表示服务存活，关闭窗口 = 停止服务。

三步流程

1

收集链接

从小红书、抖音、B站等平台复制视频或图文的分享链接

2

粘贴链接

将链接粘贴到输入框中，每行一个链接（最多支持20个）

3

批量下载

点击「批量解析」，等待处理完成后下载视频、封面和文案

V25 新功能

  • 结果卡片默认双列排列，结果区工具栏「排列」可切换单列/双列（选择会被记住）
  • iOS 风命名规则分段控件，替代旧版下拉框
  • 标签以黄色胶囊 chips 独立展示；封面左上角显示解析来源（DouParse / 本地解析）
  • 颜色语义：绿 = 解析/下载主流程，蓝 = 逐字稿/转写，黄 = 标签

启动方式

  • 一键启动：双击 start-videoparser.bat（自动预加载模型 + 自动打开浏览器）
  • 开机常驻（懒加载）：启动文件夹（Win+R → shell:startup）里的 videoparser-autostart.bat 开机后静默启动服务器，约 84MB 内存、CPU 零占用；首次转写时才加载模型（多等几秒）
  • 停止服务：双击 stop-server.bat；取消开机自启：删除启动文件夹里的 videoparser-autostart.bat

首次运行须知

  • 首次启动 transcribe_server.py 会自动安装依赖（faster-whisper、flask、imageio-ffmpeg）并下载 Whisper base 模型（约 145MB），需几分钟
  • 更高转写精度：python transcribe_server.py --model small
  • 其他参数：--port 8765 改端口；--no-browser 启动后不弹浏览器

逐字稿工作原理

点击「提取并转写」后自动完成：下载视频 → 上传到本地服务器 → FFmpeg 提取音频 → Whisper 转写 → 结果填入文本框 → 一键下载 TXT。全程本地完成，隐私安全。

手机端（PWA）

手机与电脑同一 WiFi，浏览器访问 http://<电脑IP>:8765（电脑上先运行 bat 启动服务器），可添加到主屏幕当 App 使用。

一次最多可以解析多少个链接？▼
一次最多支持20个链接。如果输入超过20个，系统会自动截取前20个进行解析。
为什么有些链接解析失败了？▼
可能原因：1) 链接已失效或被删除；2) 平台反爬限制；3) 网络问题。解析失败时可以点击"编辑/复制"自行填写信息后下载。本工具会依次尝试 DouParse API 和 HTML 代理解析两种方式，最大化解析成功率。
文件命名规则是什么？▼
命名规则可在输入区域下拉切换：

规则1 - 博主_Video_序号：博主名称_Video_01 / 博主名称_Photo_01 / 博主名称_Txt_01
规则2 - Video_序号_博主_标题：Video_01_博主名称_视频标题 / Photo_01_博主名称_视频标题 / Txt_01_博主名称_视频标题

逐字稿（Transcript）固定为：博主名称_视频标题

单个下载时不加序号（规则1：博主_Video / 规则2：Video_博主_标题）。批量下载时可自定义起始序号（如从3开始编号），可选择视频/封面/文案其中一种类型，下载方式可选打包ZIP或逐个下载。
支持哪些平台？▼
当前支持小红书、抖音、B站、快手、微博、视频号等主流平台的视频和图文链接解析。
批量解析是免费的吗？▼
本工具完全免费，所有解析和下载功能均在浏览器本地完成，不收集任何数据。解析引擎优先调用免费开源的 DouParse API（支持9大平台），失败时自动回退到 HTML 代理解析。
逐字稿解析是怎么工作的？▼
V12 采用后端视频音频分离方案：先运行同目录下的 transcribe_server.py 启动本地转写服务器，然后在浏览器中打开本工具。逐字稿解析会自动完成：1) 下载视频 → 2) 上传视频到本地服务器 → 3) 服务器用 FFmpeg 提取音频轨道 → 4) Whisper 模型自动转写 → 5) 结果自动填入文本框 → 6) 一键下载 TXT。全程无需手动操作，音频提取完全在后端完成，彻底解决了浏览器 AudioContext 静音问题。
本地转写服务器怎么使用？▼
使用步骤：
1. 将 transcribe_server.py 和 video-batch-parser-v25.html 放在同一目录
2. 双击运行 transcribe_server.py（首次运行会自动安装 faster-whisper、flask 和 imageio-ffmpeg 依赖，并下载 Whisper 模型，约 145MB，需几分钟）
3. 服务器启动后，在浏览器打开 http://localhost:8765
4. 正常使用逐字稿解析，视频上传后自动提取音频并转写

模型说明：默认使用 base 模型（中文效果好、速度快），可通过 python transcribe_server.py --model small 切换更高精度模型。
为什么不用浏览器内置的语音识别？▼
之前的版本（V7-V11）在浏览器内用 AudioContext + MediaRecorder 提取音频，存在 AudioContext 被 suspended 导致静音的问题。V12 改为后端 FFmpeg 直接分离视频音频轨道，完全绕过浏览器音频 API 限制，音频提取100%可靠。转写仍使用本地 Whisper 模型，隐私安全。
